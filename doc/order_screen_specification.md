## 1. 概要とデザインコンセプト

オーダー設定画面は、試合（公式戦・甲子園・練習試合）に臨むための**スターティングラインナップ（1番〜9番の打順）、守備位置配置、投手起用ローテーション（先発・中継ぎ・抑え）、および勝負どころを握るベンチ作戦要員（代打・代走・守備固め）**を決定・管理する画面です。

### 刷新されたUI/UXコンセプト
従来の「1画面にすべてのステータスバーを詰め込んだ横長テーブル」から、**「直感的な2選手選択と能力比較」**および**「ミニ球場グラウンド上でのドラッグ＆ドロップ（D&D）」**を軸とした、視認性と操作性を極限まで高めたレイアウトに刷新しました。

- **左ペイン（名前のみ・すっきりリスト）**: 打順・守備・背番号・名前・調子アイコンのみをシンプルに表示。2選手をクリックして選択し、下部の専用ボタンで瞬時に入れ替え。
- **右ペイン上段（ミニ球場 ＆ D&D守備スワップ）**: 小さく野球場（外野芝・黒土ダイヤモンド）を表示し、9ポジションに顔・背番号・名前・適性ピンをマッピング。ピン同士をドラッグ＆ドロップして守備位置を直感スワップ。
- **右ペイン下段（2選手詳細直接比較カード）**: 左リストで選択した2名（選手A vs 選手B）の詳細ステータス、調子アイコン、保有特性、守備適性、大会成績を左右に並べて直接対比。どちらを上位打順に据えるべきか、守備適性はどうかを一目で判断可能。

## 3. 操作オペレーション詳細仕様

プレイヤーは以下の**2つの直感的なオペレーション**を状況や好みに応じて自由に使い分けることができます。

### 3.1 オペレーション①：2選手選択 ➜ ボタン入れ替え方式（確実・ミス防止）
打順の組み替えや、守備位置のスワップを最も確実に行う基本操作です。

1. **1人目の選手をクリック**:
   - 左リストの「3番 鈴木 翔」をクリック。
   - 鈴木の行が**青色ハイライト（選択A）**になり、右ペインの左カードに鈴木の詳細情報が展開。
2. **2人目の選手をクリック**:
   - 左リストの「5番 佐藤 駿」をクリック。
   - 佐藤の行が**オレンジ色ハイライト（選択B）**になり、右ペインの右カードに佐藤の詳細情報が並んで表示（直接対比ビュー）。
   - 左ペイン下部の「入れ替え操作ボタン群」がアクティブ化。
3. **目的の入れ替えボタンを押下**:
   - **`[ ⇅ 打順を入れ替える ]`**:
     - 守備位置はそのまま（鈴木=三塁手、佐藤=遊撃手）で、**打順のみをスワップ**（鈴木が5番、佐藤が3番へ）。
   - **`[ 🛡️ 守備位置を入れ替える ]`**:
     - 打順はそのまま（鈴木=3番、佐藤=5番）で、**守備位置のみをスワップ**（鈴木が遊撃手、佐藤が三塁手へ）。
   - **`[ 🔄 打順と守備の両方を完全スワップ ]`**:
     - 打順と守備位置の両方を同時に完全入れ替え。
   - **`[ ✕ 選択解除 (ESC) ]`**:
     - 選択状態をリセットし、平常表示に戻す。

### 3.2 オペレーション②：ミニ球場上でのドラッグ＆ドロップ方式（視覚的・体感的）
守備位置の入れ替えをグラフィカルに行う直感操作です。

1. **グラウンド上の選手ピンをドラッグ**:
   - 右ペイン上部のミニ球場上で、サード（三塁）の位置にある「鈴木」のピンをマウスクリック（またはタッチ長押し）してドラッグ。
2. **入れ替え先のポジションへドロップ**:
   - ショート（遊撃）の位置にある「佐藤」のピンの上へドラッグしてドロップ。
3. **瞬時に守備位置がスワップ**:
   - 鈴木と佐藤の守備位置が入れ替わり、グラウンドの守備ピン、左リストの守備バッジ、チーム守備レーティングが瞬時に自動再計算。

## 4. 各エリアのコンポーネント詳細

### 4.1 【左ペイン】スタメン打順一覧（名前のみ・すっきりリスト）
- **表示項目**:
  - `打順バッジ (1〜9)`: 円形ナンバーバッジ（通常時: 紺、選択A時: 青、選択B時: 橙）
  - `守備位置バッジ`: ポジションカラー別（投:赤、捕:紫、内野:青、外野:緑）
  - `背番号・選手名`: 視認性の高い太字フォント
  - `学年・投打`: 例 `2年・右打`
  - `調子アイコン`:
    - **絶好調**: 真紅サークル ＋ 直立上向き白矢印 `↑`
    - **好調**: オレンジサークル ＋ 斜め右上白矢印 `↗`
    - **普通**: イエローサークル ＋ 水平右向き白矢印 `→`
    - **不調**: ブルーサークル ＋ 斜め右下白矢印 `↘`
    - **絶不調**: パープルサークル ＋ 直立下向き白矢印 `↓`
  - `選択状態ピル`: `[選択 A]` `[選択 B]` または未選択時の `[選択]` ボタン
- **疲労・不調ハイライト**: 不調（↘/↓）の選手は行全体が薄い赤色で表示され、交代や打順降格の検討をアシスト。

### 4.2 【右ペイン上段】守備配置ミニ球場（グラウンド ＆ D&Dエリア）
- **球場ビジュアル**:
  - 外野の美しい天然芝、内野の黒土ダイヤモンド、白線ベースライン、マウンド。
- **9ポジション選手ピン**:
  - `守備バッジ` `背番号` `選手名` `守備適性 (◎/◯/⚠️)`
  - 左リストで選択中の選手は、グラウンド上のピンも連動して**青/橙のパルスハロー（発光枠）**で強調表示。
- **D&Dインタラクションガイド**:
  - 選択選手間に破線の双方向カーブ矢印と `⇄ D&D守備スワップ` バッジを表示し、ドラッグ操作が可能であることを明示。
- **守備レーティングHUD（球場左側）**:
  - 内野守備: `S (91)` / 外野守備: `A (82)` / 捕手肩力: `S (88)` / 二遊連係: `S`
  - 左右打席比: `左5 / 右4` / 総失点抑止力: `94点`

## 5. まとめ

本仕様により、オーダー設定画面は**「左でシンプルに選び、右でじっくり比較し、ボタンまたはD&Dで直感的に変更する」**という、プレイヤーのストレスを極限まで排除した理想的な操作体験を実現します。
