## 1. 概要と試合進行アーキテクチャ

本作「高校野球シミュレーション5（KokoSim 5）」の試合画面は、**「テレビ中継の超望遠リアル構図」**と**「現場を激走するダイナミック3Dカメラ」**を融合し、監督として1球ごとに深く思考・采配できる本格高校野球ゲームの心臓部です。

完全サーバーレス構成（TypeScript + Three.js）により、全シミュレーション・物理演算・描画がブラウザ内でミリ秒単位で直接実行され、**遅延ゼロ・60fpsの快適な操作性**を保証します。

## 2. 3Dビュー ＆ ダイナミック・カメラワーク仕様

### 2.1 投球画面（TV中継視点：Pitch Broadcast View）
![甲子園球場 TV中継投球画面](./images/koshien_pitch_final.jpg)

- **カメラ仕様**:
  - **位置**: バックスクリーンやや右上の高所スタンド（センター方向）。
  - **画角（FOV）**: $14^\circ \sim 18^\circ$ の超望遠レンズ画角。
  - **構図**: 投手マウンド、バッターボックス、捕手、球審が一直線に収まり、背後には何万人もの超巨大すり鉢状スタンドが画面上部いっぱいまでそびえ立つ。
- **画面HUD（情報レイアウト）**:
  - **上部中央スコアボード**: イニング、スコア（青雲 3 - 2 九国大付）、BSOカウントランプ、風速・風向。
  - **画面左側（投手パネル）**: 顔アイコン、投球数（85 Pitches）、ERA、**横長スタミナゲージ（緑 ➜ 黄 ➜ 赤）**、球種・球速。
  - **画面右側（打者パネル）**: 顔アイコン、打順・守備位置、打率、HR数、**直下に打席ごとの結果カラータイル（安打＝赤、凡退＝青、四球＝緑）**。
  - **左下ミニマップ**: 現在の走者状況（1・2塁等）、守備体系ラベル（「通常シフト」「前進守備」等）、守備9人の位置ドット。
  - **右下「作戦采配ドロワー」**: 監督作戦コマンドボタン群、スピード変更ボタン、自動停止トグル。

### 2.2 打球画面（3段階ダイナミック追従：Dynamic In-Play View）
バットにボールが当たった瞬間、プレーの臨場感と戦況把握を最大化するため、**3段階のカメラワーク遷移**をミリ秒単位でスムーズに行います。

#### ① 打った直後：内野全景ハイアングル ＆ トラッキングHUD（全体把握：約0.3〜0.5秒）
![打った直後の内野全景ハイアングル映像](./images/infield_ground_wide.jpg)
- バックネット裏スタンド上段からの見下ろし俯瞰画角で、ダイヤモンド全体と打球の飛翔コースを一瞬で全体把握。
- **画面左下 TRK-STATS（トラッキングHUD）**:
  - `投球`: 球速 144km/h / 外角低め スライダー
  - `打球初速 (Exit Velocity)`: **158 km/h**
  - `打球角度 (Launch Angle)`: **12°** (鋭いゴロ・ライナー)

#### ② 捕球の瞬間：現場寄りクローズアップ（約0.5〜0.8秒）
![捕球の瞬間 寄りのクローズアップ映像](./images/infield_ground_closeup.jpg)
- カメラが打球を捕球する遊撃手の足元へ急速ズーム。
- 砂煙を巻き上げてスライディングし、逆シングルで捕球するスーパープレーを至近距離でダイナミックに演出。

#### ③ ベース到達クロスプレー ＆ 判定コール
- 一塁（または本塁）ベース上へカメラがスムーズにパンし、送球到達と走者の足の駆け抜け・ヘッドスライディングを至近距離で捉える。
- 審判のド派手な判定カットイン（「SAFE!」「OUT!」）と大歓声エフェクト。

## 3. 監督作戦コマンド体系 ＆ 発動効果ロジック

高校野球の現場において、監督がベンチから選手に伝えるリアルな指示を完全網羅。精神論的な「打たせて取れ」「三振狙い」を排除し、**「具体的で技術的な戦術指示」**に特化しています。

### 3.1 攻撃時（打席中）作戦コマンド

| コマンド名 | コマンド概要・戦術意図 | 発動効果・パラメータ補正 | リスク・デメリット |
| :--- | :--- | :--- | :--- |
| **⚡ 積極打法** | カウント0-0やファーストストライクから、甘い球を逃さず打ちに行く指示。 | ・初球スイング率 **+40%**<br>・甘いコース（中央・高め）への長打率 **+25%**<br>・初球○ 特性との相乗効果極大 | ボール球に手を出して初球凡退するリスクが小幅増加。 |
| **➡️ 逆方向意識** | 引っ張らず、右打者ならライト方向、左打者ならレフト方向へ流し打つ進塁打指示。 | ・流し打ち方向への打球確率 **+60%**<br>・一塁走者を二塁へ進めるゴロ進塁打成功率UP<br>・外角球へのコンタクト率 **+20%** | 引っ張り方向への長打・本塁打率は大幅ダウン（-50%）。 |
| **⬇️ 低め見逃せ** | 決め球として投じられるワンバウンド変化球や低めボール球を見極める指示。 | ・低めボール球へのスイング率 **-60%**<br>・相手投手のスタミナ消費・四球獲得率UP | 低めのストライク（見逃しストライク・見逃し三振）を取られるリスクあり。 |
| **⬆️ 高め見逃せ** | 釣り球となる高めのボール球ストレートを見極める指示。 | ・高めボール球へのスイング率 **-60%**<br>・フライアウト率の低下 | 高めストライクゾーンを攻められた際に見逃しリスクあり。 |
| **💥 強振** | 外野の頭を越す長打・ホームランを狙う強打指示。 | ・打球初速 **+10%**、長打・本塁打確率 **+35%**<br>・パワーヒッター特性との重複発動 | ミートカーソル縮小、空振り三振率・ポップフライ率が増加。 |
| **🎯 ミート重視** | 確実に出塁・安打を狙うコンパクトな打撃指示。 | ・ミートカーソル拡大、コンタクト率 **+30%**<br>・三振率激減、ライナー・クリーンヒット率UP | 長打・本塁打はほぼ出なくなる。 |
| **✋ 待球（待て）** | バットを振らず、相手投手の制球難・球数増加・四球を狙う指示。 | ・スイング率 **0%**（完全見逃し）<br>・相手投手の球数を確実に消費 | ストライクを2球先行されると追い込まれる。 |
| **⚾ 送りバント** | 走者を確実に次塁へ進める犠打指示。 | ・バント転がり速度の最適化（一塁線・三塁線）<br>・走者進塁成功率 **85〜95%**（打者バント適性に依存） | 打者自身は高確率で一塁アウト。 |
| **🏃 セーフティバント** | 俊足打者が内野の意表を突いて自ら出塁を狙う奇襲指示。 | ・三塁手・一塁手の前進守備がない場合に内野安打率UP<br>・打者走力A以上で成功率急上昇 | 捕手正面に転がると簡単なアウトに。 |
| **🔥 ヒット＆ラン** | 投球と同時に走者がスタートを切り、打者がゴロを転がして一・三塁を作る指示。 | ・併殺（ゲッツー）を100%防止<br>・単打で走者が一気に三塁へ到達 | 打者が空振りした場合は走者が盗塁死するリスク大。 |
| **🚨 スクイズ** | 3塁走者が投球と同時に本塁へ突入し、バントで1点を確実にもぎ取る指示。 | ・本塁生還率極大（バントが転がればほぼ1点確約） | 空振りや小フライ時は三塁走者がダブルプレーで憤死。 |

## 4. 試合進行テンポ ＆ 自動一時停止（Auto-Pause）仕様

### 4.1 ゲームスピード切替
画面右下の作戦コントロールバーから、いつでも瞬時にスピードを変更可能です。

| スピード設定 | 演出挙動 | 推奨プレイスタイル |
| :--- | :--- | :--- |
| **[ 1.0x (等倍) ]** | 全投球フォーム、打球追従、捕球スライディング、判定コールを完全等倍再生（60fps）。 | 開幕戦、決勝戦、大事な局面をじっくり観戦したい時。 |
| **[ 1.5x (推奨) ]** | 投球間隔を短縮し、ダイナミックカメラの遷移速度を1.5倍速化。 | 1球ごとの采配を楽しみつつ、サクサク試合を進めたい時。 |
| **[ 2.0x (高速) ]** | アニメーションを倍速化し、ファウルやボール判定時の演出を即時スキップ。 | テンポ重視で短時間で試合を進めたい時。 |

### 4.2 ピンチ・チャンス自動一時停止（Auto-Pause）機能
画面内に常時配置される `☑ ピンチ・チャンスで自動一時停止` スイッチをONにしておくことで、高速進行中（1.5x/2.0x）であっても、**勝負の分かれ目となる決定的な場面で自動的にゲームがストップし、監督の作戦采配を促します**。

#### 自動停止が発動する5大トリガー
1. **得点圏チャンス到来**:
   - 走者二塁、走者三塁、または満塁になった瞬間。
2. **終盤の大ピンチ**:
   - 7回以降で得点圏に走者を背負った時、または一打同点・逆転の走者が出塁した瞬間。
3. **先発投手のスタミナ限界警告**:
   - 投手の残スタミナが **25%以下**、または球数が **100球** を超えた直後の打席。
4. **相手チームの重要采配発動**:
   - 相手ベンチが代打の切り札を起用した時、またはエースリリーフ投手を投入した瞬間。
5. **最終回・サヨナラの危機 / チャンス**:
   - 9回裏（または延長タイブレーク）の勝敗決着イニング。

> **💡 自動停止時の演出**:
> 勝負の局面になると、**「ピピッ！」という緊迫感あるアラート音**とともに画面がスローダウンして停止。画面右下の作戦ドロワーが自動的に開き、金色に輝く `[ CHANCE! 采配指示 ]` または赤色の `[ PINCH! 守備采配 ]` バッジが点滅して監督の決断を待ちます。

## 5. まとめ

本仕様により、3D試合画面は単にアニメーションを眺めるだけの観戦モードにとどまらず、**「積極打法で初球を仕留めるか」「逆方向へ転がして進塁打を狙うか」「走者警戒でクイック配球に変えるか」**という、高校野球監督ならではの極限の駆け引きと緊迫感をプレイヤーに提供します。

また、1.5x/2.0xの快適なスピード感とAuto-Pauseの組み合わせにより、**「ストレスのない快適なテンポ」と「勝負所での濃密な采配体験」の完全な両立**が実現します。
