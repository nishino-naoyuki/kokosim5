# 高校野球シミュレーション5（KokoSim 5）
## 試合前オーダー作成画面 ＆ 試合中選手交代画面（守備時・攻撃時）詳細仕様書

- **文書バージョン**: 2.0.0
- **最終更新日**: 2026-10-21
- **対応画面解像度**: 1376 × 768 px (16:9 / 96DPI)
- **対象フェーズ**: 大会・試合進行フェーズ（実戦直前準備 ＆ インゲーム采配）

## 1. 概要と画面の位置付け

高校野球シミュレーション5において、チームの勝敗を分ける最も重要な戦術的介入ポイントが**「試合前オーダー作成」**と**「試合中の選手交代（守備時／攻撃時）」**です。

通常オーダー画面（平時の基本オーダー設定）で確立された**「左ペインにすっきりリスト（名前・調子アイコン・守備位置）」＋「右ペイン上部にミニ球場（グラフィカル守備配置・D&D操作対応）」＋「右ペイン下部に2選手直接比較カード」**という直感的で優れたUI/UX思想を全面的に踏襲しています。

試合中においては、**守備時（グラウンド守備9人、投手継投・守備変更・伝令）**と**攻撃時（本塁打者、塁上走者、代打・代走、次イニング守備予約）**で操作対象や判断材料が大きく異なるため、それぞれの状況に特化した最適化インターフェースを提供します。

```
【実施中大会画面】
   └─ [ ⚔️ 試合前準備（スタメン決定）へ進む ]
         │
         ▼
【試合前オーダー作成画面】（本仕様書 第2章）
   ├─ 相手先発（左腕・小手川）の対策スカウト情報の確認
   ├─ 当日の各部員「調子アイコン」を反映したスタメン9名＋打順の最終編成
   ├─ 「対左投手 最適化」や「調子優先 自動編成」などのアシスト機能
   └─ [ ⚾ このオーダーで試合開始！ ]
         │
         ▼
【試合中（投球画面・打球画面）】
   └─ [ タイム / 作戦 ] ➜ [ 選手交代 ]（またはピンチ/チャンス時の自動停止）
         │
         ├─────────────────────────────────┐
         ▼                                 ▼
【試合中選手交代画面・守備時】（第3章）   【試合中選手交代画面・攻撃時】（第4章）
   ├─ 守備9人＋ベンチ控え（投手・野手）     ├─ 攻撃中（打者・塁上走者）＋ベンチ代打代走
   ├─ ミニ球場（走者状況・守備シフト・D&D） ├─ クローズアップ球場（走者生還率・D&D）
   ├─ 現投手 vs リリーフ投手直接比較        ├─ 現打者 vs 代打の直接比較＆期待値予測
   ├─ 投手交代 / 守備変更 / 伝令指示        ├─ 代打 / 代走投入 ＆ 次イニング守備予約
   └─ [ 試合再開 ]                           └─ [ 試合再開 ]
```

## 5. 操作フローとインタラクション仕様

### 5.1 2選手選択 ＆ 「入れ替え」ボタン操作フロー
1. 左ペインのリスト、またはミニ球場上の選手をクリックして1人目（選手A）を選択（シアン色の枠線でハイライト）。
2. ベンチ控えリスト、または別の守備位置の選手をクリックして2人目（選手B）を選択（オレンジ色の枠線でハイライト）。
3. 右ペイン下部の「直接比較カード」に選手Aと選手Bの詳細パラメータ、特性、相性、交代によるシミュレーション結果が並列表示される。
4. 中央の「入替 / 交代」ボタンをクリック（またはEnterキー押下）することで、瞬時に入れ替えが反映される。

### 5.2 ドラッグ＆ドロップ（D&D）操作フロー
- **守備時**:
  - ベンチのリリーフ投手をマウンドの投手アイコンへドラッグ ➜ 投手交代。
  - 球場上の野手アイコン同士をドラッグ＆ドロップ ➜ 守備位置の入れ替え。
  - ベンチの守備固め選手を外野・内野の守備位置へドラッグ ➜ 守備固め交代。
- **攻撃時**:
  - ベンチの代打選手を本塁打者アイコンへドラッグ ➜ 代打起用。
  - ベンチの代走選手を二塁・三塁走者アイコンへドラッグ ➜ 代走起用。

### 5.3 キーボードショートカット
- `↑ / ↓`: 左ペインの選手選択カーソル移動
- `Tab`: 選択対象（現在選手 ⇄ ベンチ控え）のフォーカス切り替え
- `Enter`: 交代の決定
- `Esc`: モーダルを閉じる / 采配をキャンセルして試合画面へ復帰
- `D`: 守備時「伝令を送る」ショートカット

## 6. まとめ

本仕様により、「通常オーダー画面」「試合前オーダー作成画面」「試合中選手交代画面（守備時／攻撃時）」の全画面において、**「左リスト ＋ 右上ミニ球場 ＋ 右下直接比較」**という統一感のある卓越した操作体系が完成しました。

特に守備時と攻撃時で変化する高校野球監督のリアルな思考（「継投のタイミング」「伝令でのピンチ凌ぎ」「代打勝負と捕手交代のジレンマ」「代走投入による生還率アップ」）が視覚的・直感的にサポートされ、プレイヤーはストレスなく熱い采配ドラマに没頭することができます。
