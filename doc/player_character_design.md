## 1. キャラクターデザインの基本方針

デフォルメ（2〜3頭身のちびキャラ）ではなく、高校球児の真剣さ・躍動感・リアルな体格を伝える**「本格スポーツアニメ調（6.5〜7頭身）」**を採用します。

### 1.1 エース投手 キャラクター設定シート
投手特有のしなやかさと引き締まった筋肉、集中した表情や投球モーション、ユニフォームの着こなしを定義したイメージです。

- **頭身バランス**: 約6.5〜7頭身。現代的でスマートかつアスリートとしての説得力があるプロポーション。
- **表情・演出**: 通常時（真剣）、投球時（集中・気迫）、ピンチ時、勝利・敗戦時の表情差分。

## 2. ユニフォーム設計仕様（確定版）

ご要望に基づき、**「胸のマーク・校名ロゴは省略（完全クリーン）」**とし、シンプルかつ全国の有名校・伝統校の個性をしっかり再現できる厳選パラメータで定義します。

### 2.1 ユニフォーム設定パラメータ一覧

| 項目 | パラメータ名 | 設定値の例 | 説明 |
| :--- | :--- | :--- | :--- |
| **帽子（クラウン）** | `cap_crown_color` | 紺、黒、エンジ、緑、白、グレー等 | 帽子の胴体（頭部）の色 |
| **帽子（つば）** | `cap_visor_color` | 赤、黒、紺、同色等 | 帽子のつば（バイザー）の色（ツートン対応） |
| **ユニフォーム基本色** | `uniform_base_color` | 白、アイボリー（生成り）、グレー、淡青等 | シャツおよびパンツの全体的な地色 |
| **デザインパターン** | `uniform_pattern` | **① ノーマル（無地）**<br>**② 縦じま（ピンストライプ）**<br>**③ 1本ライン（襟・袖・側面に1本線）** | ユニフォームの造形・ラインスタイル |
| **ライン色** | `line_color` | 紺、黒、赤、青、エンジ等 | 縦じま、または1本ラインの色 |
| **アンダーシャツ** | `undershirt_color` | 紺、黒、赤、ロイヤルブルー、緑、エンジ等 | 首元および袖から覗くアンダーシャツの色 |
| **背中** | `back_number` | 1 〜 18（または20） | 背中に大きく表示する背番号（白布に黒/濃色数字） |
| **ソックス デザイン** | `socks_pattern` | **① 無地**<br>**② 1本ライン**<br>**③ 2本ライン** | ストッキングの柄スタイル |
| **ソックス 地色** | `socks_base_color` | 紺、黒、白、エンジ、緑等 | ソックスのメインカラー |
| **ソックス ライン色** | `socks_stripe_color` | 白、黄、赤等 | ソックスに入るラインの色 |

## 3. ポジション・能力に応じた体型バリエーション

| タイプ | 代表ポジション / 役割 | 特徴・プロポーション | 主な能力傾向 |
| :--- | :--- | :--- | :--- |
| **① スラッガー（強打者型）** | 一塁手、三塁手、4番打者 | 骨太で厚みのある胸板、太い腕・首周り。ヘルメット装着時の威圧感。 | パワーA〜S、長打特化 |
| **② アスリート（俊足巧打型）** | 中堅手、遊撃手、1・2番打者 | 引き締まった細マッチョ体型。俊敏さと身軽さを感じさせるフォルム。 | 走力A〜S、守備範囲広 |
| **③ パワー・アンカー（捕手・重量型）** | 捕手、大柄な投手 | 体幹が太く安定感のある体つき。捕手防具（プロテクター・レガース）が映える。 | 肩力、捕球、スタミナ |
| **④ ヤング・ルーキー（軽量・若手型）** | 1年生新入部員、小柄な選手 | やや小柄で初々しさのある体型。成長の余白を感じさせるシルエット。 | 成長率高、初期値控えめ |

## 4. 描画・実装上のメリット

1. **胸ロゴ省略による優位性**:
   - 3Dモデルや2Dテクスチャ上で文字の歪みや解像度不足を気にする必要がなく、描画負荷が非常に軽い。
   - 実在校の商標・著作権リスクを自然に回避しつつ、カラーリングとシルエットで「あの高校だ！」と直感的に伝わる。
2. **データの軽量性**:
   - 全4,000校のユニフォームデータがカラーコード数個＋Enum2個（数バイト程度）で表現可能。
   - プレイヤーによるオリジナルユニフォーム編集機能も極めてシンプルなUIで実装可能。

## 5. 選手フェイス（アバター）生成エンジン仕様（8,400億通り超の非重複設計）

全国4,000校で毎年40,000人（10年で40万人）の新入部員が生成される高校野球シミュレーションにおいて、**「同じ顔の選手が重複して興ざめする」事態を完全に排除**するため、**8,400億通りを超える超膨大モジュラーパーツ ＋ パラメトリック微調整方式**を採用します。

### 5.1 モジュラーパーツ構成と組み合わせ総数

| パーツ分類 | バリエーション数 | 主な内訳・スタイル |
| :--- | :---: | :--- |
| **輪郭（フェイスライン）** | **12種** | 丸顔、角型（がっしり）、逆三角、卵型、面長、エラ張り、頬骨高め、ふっくら等 |
| **肌トーン** | **8段階** | 色白、標準、健康的な肌色、日焼け、小麦、浅黒、漆黒褐色など |
| **髪型** | **32種** | 五厘坊主、一分刈り、三分刈り、五分刈り、角刈り、スポーツ刈り、ツーブロック、短髪アシメ、くせ毛短髪、直毛ショートなど（高校野球の規律に即した清潔感あるスタイル） |
| **髪色** | **6色** | 漆黒、ナチュラルブラック、ダークブラウン、栗色、アッシュブラック等 |
| **眉の形状** | **18種** | 太眉、凛々しい眉、への字眉、細眉、上がり眉、平行眉、薄眉、三日月眉など |
| **目の形状** | **28種** | 切れ長、パッチリ、タレ目、ツリ目、三白眼、一重、二重、奥二重、糸目、鋭い眼光など |
| **瞳の色** | **6色** | 濃黒、ダークブラウン、ライトブラウン、ヘーゼル、琥珀色など |
| **鼻の形状** | **14種** | 筋の通った高い鼻、団子鼻、鷲鼻、小鼻、上向き鼻、直線鼻など |
| **口・唇の形状** | **18種** | 引き締まった一文字、微笑み、厚い唇、薄い唇、開口、八重歯など |
| **固有パーツ（ほくろ・傷）** | **12種** | 目元ほくろ、口元ほくろ、そばかす、頬の傷、特徴なし等 |
| **体格・首の太さ** | **5段階** | 細身、標準、がっしり、重量級、アスリート |

$$\text{総組み合わせ数} = 12 \times 8 \times 32 \times 6 \times 18 \times 28 \times 6 \times 14 \times 18 \times 12 \times 5 = \mathbf{842,764,124,160 \text{ 通り（約8,428億通り）}}$$

### 5.2 パラメトリック微調整（連続値オフセットによる実質無限化）
パーツの組み合わせに加え、以下のパラメータを **$\pm 5\% \sim \pm 8\%$ の範囲で微小オフセット変形**させます：
- 目の左右間隔（目幅）
- 目の上下位置
- 眉の傾き角度（$\pm 8^\circ$）
- 鼻の上下位置およびサイズ
- 口の上下位置

これにより、同じパーツが選ばれた場合でも**ミリ単位で顔の印象が異なり、数学的に完全同一の顔が出現する確率はゼロ（実質無限）**となります。

### 5.3 決定論的レンダリング（Seed方式）と超軽量データ構造
- 選手データには、顔の画像ファイルそのものを保存するのではなく、**64bit整数の `faceSeed`** のみを保持します（容量わずか8バイト）。
- 画面表示時、SVG / Canvas ベクター描画エンジンが `faceSeed` から擬似乱数系列（PRNG: xoroshiro128+ 等）を生成し、パーツIDとオフセット値を瞬時に確定して 60fps でミリ秒描画します。
- これにより、全国40万人の選手が生成されても、メモリやストレージを一切消費せず、何万回画面をリロードしても完全に同じ顔が決定論的に再現されます。
