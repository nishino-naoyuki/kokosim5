# 高校野球シミュレーション5 (KokoSim 5)
## 通常画面仕様書：選手一覧画面（ロスター管理）＆ 詳細ポップアップ

---

## 1. 画面概要とコンセプト

選手一覧画面は、プレイヤー（監督）が部員全員（1〜3年生、18〜30名前後）の能力、適性ポジション、調子、特性能力（特殊能力）を一目で把握し、オーダー編成や育成方針の決定を行うための**チームマネジメント画面**です。

テーブル形式による直感的な一覧性を備え、**任意の選手行をクリックすることで、高精細な立ち絵イラストと全パラメーターが確認できる「選手詳細ポップアップモーダル」**が展開されます。

---

## 2. 画面ビジュアル

### ① 選手一覧テーブル画面（基本表示）
部員全員のステータスが綺麗に横並びで整理され、タブ切り替えやソートで即座に目的の選手を抽出できます。
![選手一覧画面](./images/player_list_screen.jpg)

### ② 選手詳細ポップアップモーダル（選手行クリック時）
任意の選手行をクリックすると背景が暗転し、画面中央に大型モーダルウィンドウが展開されます。
![選手詳細ポップアップモーダル](./images/player_detail_modal.jpg)

---

## 3. 選手一覧テーブル 仕様

### 3.1 画面上部：フィルタ ＆ ソートコントローラー
| コントロール | 選択肢 | 機能 |
| :--- | :--- | :--- |
| **ポジションフィルタ** | `[全員]` `[投手]` `[捕手]` `[内野手]` `[外野手]` | メインポジションによる絞り込み |
| **学年フィルタ** | `[3年]` `[2年]` `[1年]` | 学年別の絞り込み表示 |
| **ソート順プルダウン** | `総合力順` / `打力順` / `守備順` / `球速順` / `学年順` / `背番号順` | クリックで昇順・降順並べ替え |

### 3.2 テーブル列定義（カラム一覧）
テーブルの各行はマウスホバーでハイライトされ、クリック可能であることが視覚的に明示されます。

| 列名 | 表示内容 | 備考 |
| :--- | :--- | :--- |
| **顔 / 背番号** | 帽子着用のアニメ調顔アイコン ＋ 背番号（例: `#2`, `#18`） | 選手ごとの個別フェイスグラフィック |
| **氏名** | 選手氏名（例: `柘山 隆太`） | |
| **学年** | 学年バッジ（`3年` `2年` `1年`） | 学年カラーで識別（3年=橙、2年=青、1年=緑） |
| **メイン** | メインポジションバッジ（`投` `捕` `一` `二` `三` `遊` `左` `中` `右`） | 最も得意とする守備位置 |
| **サブ** | サブポジション適性（例: `二○ 三△`, `一○ 外△`） | ○＝本職に近い守備力、△＝守備力ペナルティありで起用可能 |
| **打撃能力** | ミート（コンタクト）/ パワー のランク＆ゲージ（例: `ミートA パワーS`） | ランク（S〜G）＋ 0〜100ゲージ |
| **守備能力** | 走力（スピード）/ 肩力 / 守備力 のランク（例: `走B 肩A 守S`） | 守備適性に応じた総合値 |
| **投手能力** | 球速（km/h）/ 制球（コントロール）/ スタミナ（例: `150km/h A コントロールB`） | 野手専任の場合は「`-`」と非表示 |
| **特性能力** | 特殊能力バッジ（例: `[チャンス◎]` `[守備職人]` `[レーザービーム]`） | 選手の個性・プレイスタイルを表す青特/緑特バッジ |
| **調子** | 調子アイコン（`絶好調` `好調` `普通` `不調` `絶不調`） | 試合や練習効率に影響するフェイスマーク |

## 4. 選手詳細ポップアップモーダル 仕様

選手行をクリックすると、背景テーブルに暗転マスク（オーバーレイ透過率50%）が適用され、画面中央にモーダルが展開します。
本シミュレーションのリアリティと戦術性を担保するため、全13項目のパラメータ（すべて100がMAX）および打撃成績3区分（通算・公式戦・全国大会）を表示します。

### 4.2 選手パラメータ体系（すべて 100 がMAX）

本シミュレーションの選手能力は、従来の単純な「パワー」「ミート」にとどまらず、打球物理・守備AI・メンタルに直結する以下の13項目で構成されます。

| パラメータ名 | 最大値 | 役割・シミュレーション上の影響 |
| :--- | :---: | :--- |
| **長打力** | 100 | スイングスピードおよび打球の初期速度（Exit Velocity）に直結。高いほど強い打球・ホームランが出やすい。 |
| **ミート力** | 100 | バットにボールを当てる能力。芯で捉える確率、三振率の低減に影響。 |
| **選球眼** | 100 | ボール球を見極める能力。四球の獲得率、ストライクゾーンの見極め精度に直結。 |
| **走力** | 100 | トップスピードの速さ。長打時の三塁打・長駆生還、外野手の広範囲守備に影響。 |
| **加速** *(隠し値)* | 100 | **トップスピードに達するまでの速さ**。一塁駆け抜けタイム、内野手の瞬発力に影響（画面非表示・内部計算）。 |
| **捕球力** | 100 | 守備力。打球をファンブルせず確実にグラブに収める能力。エラー率に直結。 |
| **度胸** | 100 | プレッシャーのかかる場面（得点圏、終盤リード、満塁等）での能力発揮力。**公式戦や試合に出場することで経験値が蓄積し上昇**。 |
| **肩の強さ** | 100 | 野手としては送球スピード、投手としては**基礎球速（ベーススピード）**を決定。 |
| **コントロール** | 100 | 送球の正確さ（野手は50程度で実用十分）。投手としては狙ったコースへ投げるコマンド力。 |
| **投球フォーム** | 100 | フォームの再現性と力伝達効率。**「肩の強さ」と「投球フォーム」の乗算・合算で最終的な投手の最高球速（km/h）が決定**。 |
| **判断力** | 100 | 状況に応じて何をするか判断する能力（走塁の自重・進塁判断、送球先の的確さ、中継プレー判断）。 |
| **反応速度** | 100 | 主に守備時、バットインパクトから打球に対して一歩目を踏み出すまでの初動速度。 |
| **変化球** *(配列)* | 各100 | 所持する球種（スライダー、カーブ、フォーク、チェンジアップ等）それぞれの「キレ」を示す配列データ。 |

#### その他属性
- **投打（利き腕）**: 右投右打、右投左打、左投左打、右投両打、左投両打
- **特性（Traits）**: 能力値以外の個性・プレイスタイル。
  - 例：`フライボールバッター`（打球角度が上がりやすい）、`グラウンドボールピッチャー`（ゴロを打たせやすい）、`キャッチャー◎`（投手スタミナ消費-15%）、`強肩`、`サヨナラ男`、`ムードメーカー` 等。
- **調子**: **`-5` 〜 `+5` の11段階**（絶好調+5、好調+1〜+4、普通0、不調-1〜-4、絶不調-5）。試合中のパラメータ補正や疲労蓄積速度に影響。

### 4.3 打撃成績（3大区分の常時記録と対比表示）

打撃成績は、プレイヤーが選手の成長や大舞台での強さを実感できるよう、以下の**3つの区分**に厳密に分けて集計・表示されます。

1. **通算成績 (Career)**: 練習試合、春季・秋季大会、夏の地方予選、甲子園全国大会の**すべての対外試合合算成績**。
2. **公式戦成績 (Official Matches)**: 都道府県大会（春季・秋季・夏の地方予選）およびブロック大会の成績。
3. **全国大会成績 (National Tournaments)**: 阪神甲子園球場（選抜高校野球大会・全国高校野球選手権大会）および明治神宮大会の**全国大舞台限定成績**。

#### 成績表示項目
- 打率（AVG）、試合数（G）、打数（AB）、安打数（H）、本塁打数（HR）、打点（RBI）
- 三振数（SO）、四球数（BB）、盗塁数（SB）、出塁率（OBP）、長打率（SLG）、OPS
